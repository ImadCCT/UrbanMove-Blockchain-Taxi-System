# UrbanMove Blockchain Taxi System

## Project Overview
A blockchain-based taxi booking and payment prototype developed for UrbanMove Taxi Services, an Irish taxi company.

## Project Objectives
- Implement automated taxi bookings using smart contracts.
- Secure passenger and driver transactions.
- Automate taxi fare payments.
- Improve transparency and transaction integrity.
- Explore blockchain privacy and regulatory considerations.

## Technologies
- Solidity
- Remix IDE
- Ganache
- MetaMask

## Project Structure
- contracts/: Solidity smart contracts.
- documentation/: Assignment report, diagrams and supporting evidence.
